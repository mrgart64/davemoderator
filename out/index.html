Deteksi Pesan Penipuan
dengan DaveMod.

DaveMod adalah AI moderasi pesan berbasis neural network yang dilatih dengan dataset dari berbagai jenis pesan, dilengkapi dengan visualisasi diagram yang menampilkan beberapa kemungkinan pesan dan juga memberikan saran tentang apa yang harus dilakukan. DaveMod sangat responsif dan ringan karena tidak menggunakan API AI eksternal.

// Pilar Pengembangan Solusi
01 / RECOGNIZE

Mengenali (Recognize)

Membantu pengguna menilai pesan, tautan, tawaran, atau profil mencurigakan dengan menunjukkan tanda bahaya dan alasannya.

02 / LEARN

Belajar (Learn)

Melatih kemampuan mental pengguna melalui skenario realistis, simulasi interaktif, latihan pengambilan keputusan, dan umpan balik.

03 / ACT

Bertindak (Act)

Memandu pengguna menentukan langkah selanjutnya, seperti daftar periksa keamanan, pengamanan akun, panduan pelaporan, dan cara memperingatkan orang lain.

// MODEL ARCHITECTURE & ADVANTAGES

Mengapa DaveMod Lebih Unggul?

Dirancang khusus dengan kapabilitas tinggi untuk mendeteksi potensi penipuan digital secara instan, transparan, dan aman di browser Anda.

100% Client-Side Processing

Model AI berjalan langsung di dalam browser menggunakan ONNX Runtime Web. Teks pesan Anda tidak pernah dikirim atau disimpan ke server eksternal, menjamin privasi data 100% aman.

STATUS:Zero Data Leak

Analisis Real-Time Instan

Mampu memproses kalimat, pola bahasa gaul (slang), maupun struktur pesan penipuan modern dalam hitungan milidetik saat tombol analisis ditekan atau fitur auto-deteksi aktif.

LATENCY:< 50ms

Deteksi Berbasis Konteks

Dilatih secara spesifik untuk mengenali pola manipulatif seperti tawaran kerja palsu, tautan phishing, giveaway palsu, promosi judi online, pinjol, hingga investasi bodong.

ACCURACY:High Precision

Model Efisien & Ringan

Model AI DaveMod memiliki ukuran file sangat kecil (hanya 170-250 KB), memungkinkan pemuatan cepat bahkan di koneksi internet seluler yang lambat.

FOOTPRINT:Ultra Lightweight

Transparansi Probabilitas

Tidak sekadar memberikan hasil "Penipuan" atau "Netral", AI juga menyajikan distribusi probabilitas visual dan persentase tingkat keyakinan (confidence score) dari 5 kategori terbesar secara jelas dan AI ini memiliki 10 kategori berbeda.

OUTPUT:Visual Distribution

Panduan Edukatif (Learn & Act)

Memberikan rekomendasi langkah konkret secara kontekstual untuk mengedukasi pengguna (Learn) sekaligus panduan tindakan pertolongan pertama (Act) saat mendeteksi bahaya.

FEATURE:Actionable Advice
DISCLAIMER: KEMUNGKINAN FALSE POSITIVE

Model machine learning ini beroperasi berdasarkan probabilitas statistik dan tidak dijamin 100% sempurna. Pesan sah (normal) terkadang dapat terdeteksi sebagai ancaman (False Positive). Selalu gunakan pertimbangan mandiri sebelum mengambil tindakan atau mengabaikan sebuah pesan.
